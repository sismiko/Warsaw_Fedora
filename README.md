# Warsaw_Fedora_44

Shell Script para instalar o módulo Warsaw (Guardião) no Fedora 4x. Testado até o Fedora 44.

Funciona para qualquer banco que utilize o Warsaw: Banco do Brasil, Bradesco, Itaú, ...

Utiliza o binário original do warsaw v2.22.1.

Ao baixar, certifique-se que o script instala_warsaw.sh tenha permissão de execução:

```shell
chmod +x instala_warsaw.sh

./instala_warsaw.sh

```
